# HOME.IAI.ONE

HOME.IAI.ONE is the central system portal of the wider IAI structure.

It does not replace the Charter, does not operate ecosystems, and does not act as the technology flagship itself. Its role is to help people see the system clearly before entering any specific layer.

## Core Definition

- `iai.one` is the Charter layer
- `home.iai.one` is the Portal layer
- `docs.iai.one` is the knowledge hub
- `app.iai.one` is the operator workspace
- `flow.iai.one` is the workflow and runtime flagship
- `api.iai.one` and `api.flow.iai.one` are the service interface layer
- `dash.iai.one`, `developer.iai.one`, `noos.iai.one`, and `cios.iai.one` are specialized system surfaces
- `mail.iai.one` is the delivery and communication layer

## Purpose of Home

HOME exists to make the wider IAI system understandable through:

- system definition
- role clarity
- ecosystem mapping
- correct entry paths
- visible boundaries
- routing into docs as the canonical explanation layer
